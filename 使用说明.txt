AI 自动混剪｜同事使用说明（2026-11-10）

一、安装与打开
1. 把整个文件夹解压到本地磁盘（不要直接在 ZIP 里双击启动）。
2. 双击「启动.bat」，浏览器会打开 http://127.0.0.1:8765 。黑色窗口要一直开着，关掉就等于退出。
3. 第一次使用在网页上注册自己的账号；之后打开还是同一个账号的历史记录。
4. 想检查运行环境是否完整，双击「体检.bat」。

二、不再需要 WorkBuddy
不用连 WorkBuddy、不用贴提示词、不用等回填。配音按你选的音色走：云端音色联网合成，
系统音色走随包 edge-tts（本机 F5 / GPT-SoVITS 克隆音色的网页入口已移除）。点「生成视频」一次跑完，
关掉网页也不影响已经在跑的任务。

三、配音怎么出声音（在「配音音色」下拉里挑）
1. 云端音色（推荐，默认）：火山豆包语音合成模型 2.0 的 9 个音色，云舟 / 小天 / 刘飞 /
   解说小明 / 磁性解说男声 / 大壹 / Vivi / 小何 / 清新女声。联网合成，每句约 1–2 秒，
   不用装本机权重，按量计费。凭证放在 C:\Users\<你的账号>\.workbuddy\voices\.cloud-key.json，
   不随项目包分发；没配凭证时这一组不可用，网页会写明缺什么，可改用免费音色。
2. 系统音色：云健、云扬、云希、云夏、晓晓、晓伊、辽宁晓北、陕西晓妮，共 8 个，免费、需要联网。
   本机合成的克隆音色（F5 / GPT-SoVITS）已从网页移除，下拉里不再有这一组。
3. 自己录的成品配音：在「更多设置 → 其他设置」里传音频并选中，网站只负责按它铺字幕、卡镜头。
4. 「效果试听」：用当前音色和语速念文案第一句，先听再出片。
5. 包里 defaults 目录另带一条示例音轨和字幕，走助手（MCP）接口时可以指定用它，网页上不开放这一项。

四、用参考视频的 BGM（贴一条链接就行）
1. 展开「更多设置」，在「BGM参考视频链接（可选）」里粘贴抖音 / 快手 / B站的分享链接，点「抓取」。
2. 程序会用本机浏览器把那支片子抓下来，再把里面的人声剥掉，只留伴奏当背景音乐。
   状态行会显示抓到的时长和分辨率；抓不到的会直接告诉你原因（链接不全、是图片不是视频、需要登录等）。
3. 抓完不用再选「背景音乐」，生成时自动用这条伴奏；音量已经按背景乐压过，不会盖住配音。
4. 同一条链接只会分离一次，第二次直接读缓存，不再等。
5. 只支持公开可看的视频；需要登录、付费、地区限制或平台加密的抓不到，这种就换一条，或者按第三条自己选背景音乐。
6. 链接只在你自己的账号下保存，换账号不串。
7. 「更多设置」里相关的三个开关默认全开，按需要关：
   「字幕特效」= 开场呐喊 + 声波 + 关键词变色；「点睛音效」= 开场冲击 / 叮 / 转场风；
   「参考视频用它的伴奏」= 勾着才分离伴奏，取消就退回整条原声压低当背景。
   改动会记在本机，下次打开还是你上次的选择。

五、做一条视频的步骤
0. 最左「项目管理」：点「＋ 新建项目」开一条新的；点列表里的项目即可切换，点 × 删除。
   每个项目单独保存文案、标题、音色、语速、更多设置和素材路径，切项目不会串内容；
   切过去会按该项目自己的素材路径重新读一次素材，没填路径的项目素材墙就是空的。
   内容存在本机浏览器里，按账号隔离。
1. 左边第二栏上传素材，或填本机素材目录后点「读取」。
2. 右侧第 1 块填「视频文案」（一行一句），第 2 块填「封面标题」。
3. 右侧第 3 块选「配音音色」「语速」（0.7×–1.8×），可点「效果试听」先听一句。
4. 右侧第 4 块「更多设置」拉开后有三项：
   ① BGM参考视频链接（可选）：贴抖音 / 快手 / B站链接点「抓取」，程序剥掉人声只留伴奏；
   ② 字幕特效 和点睛音效：两个开关，默认都开；
   ③ 成片保存位置：留空只存成片库，填目录或点「选择」会额外存一套 mp4 + 封面 + srt。
   最下面「其他设置」里还留着封面图上传、背景音乐库、已保存配音、导出配置。
5. 点「生成视频」，等进度条走完。完成后可「打开文件夹」「复制路径」「导出配置」。
   语速 1.0× 是正常口播（实测约 5 字/秒），调大调小按倍数走；云端音色实测 1.0× 效果最稳。

六、剪出来的样子
文案怎么排版，成片就怎么走：**一行字 = 一句话 = 一条字幕 = 一条配音**，不合并、不拆开。
写完一行就回车，别在行里手动断句；想换气就在这一行结尾加个标点。
字幕参照提供的抖音样片：中下方单行白色粗体、黑色描边，落点在画面约 66% 高度（中间偏下）。
每行字幕都显示成一行，不会因为字数多被折成两行；实在放不下（一行超过约 15 个字）才自动把这一条的字号缩小一点。
数字带单位、百分比、倍数、型号缩写会变成亮黄色加粗描边——这就是「划重点」。
片头第一屏带「呐喊」效果：字从 124% 砸下来、回弹两次，外面套两圈声波轮廓向外扩散。
点睛音效默认开：开头一下低频冲击 + 一阵风、关键词处最多三下轻「叮」、段落转场一阵风、结尾落版一个「咔」。
这三样和「呐喊 / 声波」都能在设置面板里单独关掉，见第四节第 7 条。
配音按文案原文朗读，一个字不加一个字不减；每行单独合成、单独断句，行与行之间停 0.45 秒再加段尾换气
（实际听感 0.5–0.8 秒，不是一口气连着念完，也不是每句拖很久，这个停顿就是「一行一句」的听感）。
云端音色默认语速约 5 字/秒，1.0× 就是正常口播；调快调慢按倍数走，
不用硬拉伸音频（硬拉伸会把字拉糊）。
分镜是「一句话一个镜头」，切点落在换气口上；5 秒以下两句合成一镜；只有超过 6 秒的长句才在逗号处补一刀。
要叠背景音乐就在「BGM参考视频链接」里贴链接，或在「其他设置 → 背景音乐」里选一条。

七、目前的限制
1. 云端音色要联网 + 火山凭证（写到 C:\Users\<你的账号>\.workbuddy\voices\.cloud-key.json 的
   VOLC_API_KEY），按量计费；没配就用免费系统音色，不影响出片。
2. 系统音色走 edge-tts，需要联网。网页不再提供本机克隆音色，服务端能力仅供命令行 / MCP 使用。
3. 服务只在本机开放（127.0.0.1），每台电脑的数据和账号各自独立。
4. 项目管理的数据存在本机浏览器 localStorage，换电脑 / 清浏览器数据不会带过去。
5. 参考视频抓取依赖本机的 Chrome 或 Edge（已装其一即可），并且要能正常访问那个平台；
   平台改版、需要登录或加了防盗链时可能抓不到，换链接重试即可，不影响手动选背景音乐。

八、项目内容
index.html / admin.html 网页源码；server / launcher / assets 程序；connector 里是配套技能与说明；
server/cloudvoice.mjs 是网页云端配音（音色清单 + 批量合成 + 试听），
connector/skills/voice-clone-dub/scripts/cloud-tts.mjs 是实际调云厂商的适配层；
assets/projects.js 是左侧项目管理、云端音色下拉与效果试听的前端逻辑；
runtime 是随包运行环境（node、ffmpeg、edge-tts）；defaults 是内置示例音频与字幕，defaults/sfx 里四个音效
（impact / whoosh / ding / pop）就是点睛音效，缺了不影响出片，只是没声音；想换自己的音效就同名替换。
参考视频抓取写在 server/fetchlink.mjs，人声分离用 connector 里的伴奏分离脚本；抓到的片子和分离结果放在
data/media/<你的账号>/ref 与 data/cache/refbgm 下，删掉只是下次重新抓一遍，不影响已有成片。
如果带了 voices 目录，那是本机克隆音色的音色档案，网页已不使用，不需要就整个删掉，不影响其它功能。
本包不含任何人的账号数据、MCP 令牌、测试数据库或历史成片。项目文件夹和 runtime 不要拆开。

九、从 GitHub 拿这个包 / 升级

1. 想开箱即用：去 GitHub 仓库的 Releases 下载「AI-Auto-Remix-v1.0.0-Windows-Full.zip」，
   解压到本地磁盘（不要直接在 ZIP 里双击），双击「启动.bat」。ZIP 里已带
   node、ffmpeg、ffprobe、edge-tts，不用再装运行时；云端音色和系统音色仍需要联网。
2. 想拿源码 / 自己改：git clone 仓库后，双击「安装运行时.bat」，它会下载
   Node v22.22.2 与 ffmpeg/ffprobe 放进 runtime 目录（约 150MB，只需一次）。
   edge-tts 已随仓库提供，不用另外装。装完双击「启动.bat」。
   ffmpeg.exe / ffprobe.exe 单文件超过 GitHub 普通仓库 100MB 上限，所以源码仓库里
   不放这两个大文件，完整版一律走 Release 资产。
3. 升级：Release 出了新包就重新解压覆盖；源码方式直接 git pull，
   runtime 目录和你自己的数据都不会被覆盖。

云端凭证（只有用「火山豆包 2.0」那 9 个音色才需要）
  在 C:\Users\<你的账号>\.workbuddy\voices\ 下新建 .cloud-key.json，
  照仓库里的 cloud-key.example.json 填，把 VOLC_API_KEY 换成火山新版控制台的
  X-Api-Key。这个文件不要提交到 GitHub、不要发给别人；按量计费，额度算你自己的。
  没配凭证就用免费的 8 个系统音色，出片不受影响，网页会写明缺什么。

数据放在哪
  默认在 C:\Users\<你的账号>\AppData\Local\AiAutoRemix\data，账号、素材、成片全在本机。
  仓库里不含任何人的账号数据、凭证、测试库或历史成片。要改目录，把
  「配置.example.json」另存为「配置.json」后设 dataDir。

多人怎么用
  默认「启动.bat」只监听 127.0.0.1，不要把局域网地址发给同事。
  正式分发就是把整个文件夹（或 Release ZIP）发给每个人，各自在自己电脑上跑：
  数据、素材、火山额度各自独立，每人自己配凭证，没配就用免费音色。
  项目里另带 central + local 部署（启动-中央.bat / launcher/start-central.mjs），
  适合公司统一管账号、各自本机渲染的场景，按需再用。

新建项目会清空什么（2026-11-11 更新）
  点「＋ 新建项目」后，视频文案、封面标题、音色（回默认云端音色）、语速（回 1.00×）、
  BGM参考视频链接、字幕特效与点睛音效（回默认全开）、成片保存位置、封面上传、
  素材路径、素材墙与素材选择、预览画面，以及成片 MP4 / 封面 JPG / 字幕 SRT 的下载栏，
  全部回到空白初始态，素材计数归 0。
  切回旧项目会把当时保存的文案和设置恢复回来，素材按该项目保存的路径重新读。
  清空只清界面：服务端账号目录下已上传的文件不会被删除，点「读取」或重开页面还能再读回来；
  要彻底移除某条素材，在素材卡右上角点 ✕。
